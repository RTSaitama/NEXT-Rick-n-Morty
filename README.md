# Rick and Morty Characters App

Live demo: [https://next-rick-n-morty-xxx.vercel.app/](https://next-rick-n-morty-xxx.vercel.app/)

Next.js 15 app to browse and filter characters from the [Rick and Morty API](https://rickandmortyapi.com/api).

## Features

- Grid view of characters  
- Filters by name, status, species, and gender  
- Pagination with `react-paginate`  
- Clear filters to reset results  

## Tech Stack

Next.js 15 | React 19 | Tailwind CSS 4 | Bootstrap 5 | react-paginate  

## Setup

```bash
git clone https://github.com/yourusername/rick-and-morty-app.git
cd rick-and-morty-app
npm install
npm run dev
```
